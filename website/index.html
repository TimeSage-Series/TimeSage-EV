TimeSage-EV: Agentic Time Series Analysis in Evolving Environments

TimeSage-EV measures how well agents analyze periodically released time series data, a defining challenge for agents that operate over long horizons and are expected to improve continuously.

How TimeSage-EV has evolved

The corpus is refreshed as agencies publish new data. Each snapshot fixes a window of periods so results stay comparable; newer snapshots move the window forward.

Get started

Quickstart

Python 3.10+ and uv are required; bubblewrap is optional for sandboxing the agent.

git clone https://github.com/TimeSage-Series/TimeSage-EV && cd TimeSage-EV
uv sync && source .venv/bin/activate
git clone https://huggingface.co/datasets/TimeSage-Series/TimeSage-EV evbench/scenarios

cp .env.example .env && set -a && source .env && set +a
cp experiments/example.yaml experiments/mine.yaml

# one scenario, one period
evsandbox run evbench/scenarios/easy/climate/noaa_cpc_ao_monthly_phase 2024-05 \
    --config experiments/mine.yaml

# a whole tier, periods played in order with feedback
evsandbox sweep --config experiments/mine.yaml --mode episode
evsandbox — episode · noaa_cpc_ao_monthly_phase

Scenarios
